# Native Note 手测脚本

状态：`blocked-by-device`
本手测脚本继续保留给真机线程使用，当前不再推进真实 stylus trace 录制和真机验收执行。

## D-INK-01 压感轻压/重压

前置条件

- 真机安装当前包。
- 连接支持压感的手写笔。
- 进入一份 `paged` 空白笔记。
- 笔工具为 `pen` 或 `pencil`，压力开关保持开启。

操作步骤

1. 在同一页面上连续画两条长度接近的直线。
2. 第一条尽量轻压，第二条明显重压。
3. 观察画面中的笔迹宽度变化。
4. 同时观察编辑页 debug 文本中的 `pressure=` 数值。

预期结果

- 重压笔迹明显宽于轻压笔迹。
- `pressure=` 在轻压和重压两次输入之间存在可见差异。
- 没有出现压力倒置、突变或整段等宽。

失败现象

- 轻压和重压线宽几乎一致。
- 重压反而更细，或宽度在一笔内部无规律抖动。
- `pressure=` 长期卡在固定值或明显不随力度变化。

## D-INK-02 tilt/roll 侧锋

前置条件

- 真机安装当前包。
- 连接支持 tilt/roll 的手写笔。
- 进入一份 `paged` 空白笔记。
- 当前工具切到 `pencil`。

操作步骤

1. 先用近乎垂直的握笔姿势画一条短线。
2. 再明显倾斜笔身，以侧锋姿势画第二条短线。
3. 保持倾斜，旋转笔杆方向后再画第三条短线。
4. 观察 debug 文本中的 `tilt=` 和 `roll=`。

预期结果

- 倾斜后的侧锋笔迹比直立握笔更宽、更扁。
- 旋转笔杆后，宽扁笔锋的朝向会跟着改变。
- `tilt=` 和 `roll=` 数值会随着姿势变化而变化。

失败现象

- 侧锋与直立笔迹外观基本一致。
- 旋转笔杆后笔锋朝向不变，或方向随机跳变。
- `tilt=` / `roll=` 始终接近 0 或完全不更新。

## D-INK-03 双击切笔

前置条件

- 真机安装当前包。
- 手写笔支持笔身双击或双击按键事件。
- 编辑页已打开，当前工具为 `pen` 或 `pencil`。

操作步骤

1. 先确认当前为墨水工具，并画一笔。
2. 在约 350ms 内连续两次触发笔身双击。
3. 再次落笔，确认当前是否切到 `eraser`。
4. 再做一次双击，确认是否切回最近一次墨水工具。
5. 观察 debug 文本中的 `tool=... native=...`。

预期结果

- 第一次有效双击会在 `eraser` 与最近一次墨水工具之间切换。
- 第二次有效双击可切回原墨水工具。
- debug 文本中的工具状态与实际落笔行为一致。

失败现象

- 双击后工具不切换。
- 双击后切到错误工具，或无法切回最近墨水工具。
- UI 显示与实际落笔行为不一致。

## D-INK-04 palm rejection

前置条件

- 真机安装当前包。
- 连接手写笔。
- 编辑页已打开，`palm rejection` 保持开启。

操作步骤

1. 先用笔正常书写一小段。
2. 保持笔尖继续书写，同时让手掌或另一根手指触碰屏幕。
3. 重复 2 到 3 次，覆盖短触碰和持续按压两种情况。
4. 观察 debug 文本中的 `palm=` 与 `finger=`。

预期结果

- 手掌或非笔输入不应产生新的墨迹或移动现有笔迹。
- `palm=` 计数会增长，`stylus=` 仍保持主导。
- 已有笔迹连续性不被误触打断。

失败现象

- 手掌接触时产生额外墨迹、拖动画布或移动对象。
- `palm=` 不增长，或误触被当成正常墨水输入。
- 书写过程中因为误触导致笔迹中断或跳点。

## D-INK-05 prediction 急转弯

前置条件

- 真机安装当前包。
- 连接手写笔。
- 编辑页已打开，`prediction tail` 保持开启。

操作步骤

1. 以中高速画一条直线。
2. 在笔不离屏的情况下突然做 90 度以上急转弯。
3. 连续重复 5 次，观察每次拐角附近的尾巴表现。
4. 观察 debug 文本中的 `predict=`。

预期结果

- 急转弯前出现的预测尾巴会在转角后快速回滚并收敛。
- 拐角处不会长期保留超前的尖刺或明显越界残影。
- `predict=` 会短暂增加，但转角结束后可回落。

失败现象

- 转角后仍长时间残留直线方向的预测尾巴。
- 拐角处出现明显尖刺、回弹、双折线或断裂。
- `predict=` 长时间不回落，或急转弯时完全失效。

## D-INK-06 prediction 高速短抖动

前置条件

- 真机安装当前包。
- 连接手写笔。
- 编辑页已打开，`prediction tail` 保持开启。

操作步骤

1. 用较快速度画 1 到 2 秒的短振幅抖动线。
2. 期间做几次快速停顿和重新起笔。
3. 观察尾巴是否在停顿后及时收敛。
4. 观察 debug 文本中的 `predict=` 和 `history=`。

预期结果

- 高频短抖动时预测尾巴不会无限放大。
- 停顿或抬笔后尾巴应快速消失。
- `history=`、`predict=` 会变化，但不会导致画面持续拖影。

失败现象

- 短抖动被放大成长尖刺或重复折返。
- 停顿后仍持续显示旧的预测尾巴。
- 预测尾巴与真实笔迹明显分离。

## D-DOC-01 paged 重开不跑位

前置条件

- 真机安装当前包。
- 使用 `paged` 文档。
- 页面内已有多处墨迹，至少包含 `page-0` 上的一个靠边对象。

操作步骤

1. 记录当前页面内对象相对纸张边缘的位置。
2. 执行保存并返回首页。
3. 从首页重新打开同一文档。
4. 对比 page-0 中内容相对边缘、参考线和底图的位置。

预期结果

- 重开前后 page-0 中的内容位置保持一致。
- 内容不会整体偏移、缩放或重排。
- 首页 preview 卡片与编辑页内容保持一致。

失败现象

- 重开后内容整体偏移或缩放。
- page-0 对象与边距、底图、参考线的相对位置变化。
- 首页卡片和编辑页内容不一致。

## D-DOC-02 infinite 重开不跑位

前置条件

- 真机安装当前包。
- 使用 `infinite` 文档。
- 文档内已有跨原点或跨多个网格区块的内容。

操作步骤

1. 在无限画布上记录一组参照点与网格交点的位置关系。
2. 执行保存并返回首页。
3. 重新打开同一文档。
4. 平移到原位置，观察内容与网格关系是否一致。

预期结果

- 内容与无限网格的相对位置保持一致。
- 重开后不会出现整体漂移、局部偏移或缩放错位。
- 跨原点内容不会因为重开跳到另一侧。

失败现象

- 网格和内容的相对位置变化。
- 重开后需要额外修正平移才能对齐原位置。
- 某些对象相对漂移而非整体一致。

## D-LAYER-01 PDF/HYBRID placeholder 底图层级

前置条件

- 真机安装当前包。
- 准备一份 `PDF` 文档和一份 `HYBRID` 文档。
- 两份文档都在底图上方写有明显墨迹。

操作步骤

1. 打开 PDF 文档，观察墨迹和 placeholder/PDF 底图的层级关系。
2. 缩放、返回首页、重开后再次观察。
3. 对 HYBRID 文档重复同样步骤。
4. 对比首页 preview 卡片与编辑页中的层级感知是否一致。

预期结果

- PDF 或 placeholder 始终位于 ink 下层。
- 墨迹不会被底图压住，也不会在重开后掉到底图下方。
- 首页 preview 卡片中的层级感知与编辑页一致。

失败现象

- 墨迹被底图遮挡。
- 首页卡片层级正常但编辑页异常，或反过来。
- 缩放或重开后层级顺序发生变化。

## D-HOME-01 首页 preview 卡片显示与 fallback

前置条件

- 真机安装当前包。
- 已准备 `preview-store-regression` 四类 case。
- 首页可正常进入文档列表。

操作步骤

1. 依次验证 `missing`、`corrupt`、`legacy-summary-only`、`richer-payload` 四类 case。
2. 观察卡片 badge 是否为 `Preview ready / fallback / error` 之一。
3. 观察卡片缩略图是否按 `raster -> vector -> fallback` 分支显示。
4. 用 `previewSummary` 中独有关键词进行首页搜索。

预期结果

- `missing` 和 `corrupt` 不应拖垮首页；卡片可退回 fallback 路径。
- `legacy-summary-only` 至少能显示 vector fallback，不要求 raster。
- `richer-payload` 若带 raster，应优先显示 raster。
- 搜索命中仍依赖 `previewSummary`，不会因为 preview 文件异常而退化。

失败现象

- 首页因为坏 `preview.json` 卡死、白屏或列表丢失。
- raster/vector/fallback 分支与 payload 状态不一致。
- `previewSummary` 明明存在，但搜索无法命中。
- 卡片 badge 与实际分支不一致。
